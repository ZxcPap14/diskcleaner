# 📇 DiskCleaner Pro — карта функций по темам

Что уже есть в приложении и что можно добавить. Пункты «можно добавить»
помечены усилиями: 🟢 — маленькие, 🟡 — средние, 🔴 — большие.

---

## 1. 🧹 Очистка диска

**Есть:**
- **Smart Clean** — режимы Easy (только 🟢) / Advanced, поиск по названию,
  сортировка по размеру, группы-категории с чекбоксами (☑/☐/▣), аккордеон,
  кнопки «Всё» / «Снять» / «Безопасные», прогресс и отмена сканирования.
- **Глубокая очистка** — цели по слоям A–D, план до удаления (пути, тома,
  слои, крупнейшие действия), подтверждение, честный результат: сколько
  реально освобождено по каждому тому, предупреждения о корзине/компонентах.
- **Системные цели** — корзина, Windows Temp, пользовательский Temp,
  Prefetch, кэш эскизов, WER (пользовательский + системный), дампы памяти
  и приложений, кэш Windows Update, Delivery Optimization, кэш шрифтов,
  сброс DNS, кэш шейдеров GPU (NVIDIA/AMD/Intel), INetCache, CBS/DISM/Panther
  логи (возрастные фильтры 24 ч / 30 дней).
- **Браузеры** — Chrome, Edge, Yandex, Brave, Vivaldi, Opera (все профили
  Chromium: Cache, Code Cache, GPU-кэши, Service Worker), Firefox (cache2,
  startupCache, offlineCache, shader-cache).
- **Мессенджеры и приложения** — Discord, Telegram (только медиа-кэш, tdata
  не трогаем), Slack, Teams, Zoom, Яндекс Музыка, Steam (htmlcache + depot),
  Obsidian, Epic Games (WebCache*), Adobe (Media Cache), Java Deployment
  Cache, WSL vhdx (обнаружение + подсказка по сжатию).
- **Dev-инструменты** — npm, pip, yarn, uv, bun, Rust, Gradle, Playwright,
  VS Code, Antigravity, Docker (`docker system prune`).
- **AI/ML** — Whisper, HuggingFace, LM Studio, Ollama.
- **Auto-discover** — автоматический поиск кэш-папок (cache/code cache/temp)
  в AppData с кэшированием на 5 минут; уже покрытые пути исключаются.
- **Свои правила** — добавление/редактирование/удаление папок и файлов,
  проверка защищённых путей.
- Безопасный режим (только 🟢 цели), опция «перемещать в корзину».

**Можно добавить:**
- 🟢 **Планировщик чистки Temp/корзины** — задача Windows Scheduler
  «каждую неделю», тихий запуск.
- 🟢 **Очистка по порогу свободного места** — «если на C: < 10 ГБ, предложить очистку».
- 🟡 **Больше целей**: Battle.net/GOG лаунчеры, Adobe (Camera Raw, Acrobat),
  Blender/Obsidian plugins, NuGet, Maven, Conda, Torrent-клиенты (кэш).
- 🟡 **Автообновление целей** — список очистителей в JSON, чтобы добавлять
  новые без релиза.
- 🟡 **Умный выбор дубликатов-«мусора»** — кнопка «отметить то, что
  безопасно удалить» по эвристикам (возраст, путь).
- 🔴 **Очистка других пользователей** — цели в профилях C:\Users\* (нужен
  сценарий с правами и подтверждением).

## 2. 📊 Анализ диска

**Есть:**
- Топ папок по размеру, список больших файлов, поиск пустых папок.
- Интерактивный treemap (squarify) с переходом вглубь и назад.
- Кэш результатов с кнопкой «🔄 Обновить», отмена сканирования.
- Удаление пустых папок (вложенные сначала, корень сканирования защищён).
- Контекстное меню: открыть, скопировать путь, удалить в корзину.
- Выбор диска на главной применяется к анализатору.

**Можно добавить:**
- 🟢 **Фильтры в анализаторе** — по типу файла (расширению), возрасту,
  минимальному размеру.
- 🟢 **Топ расширений** — «сколько занимают .mp4 / .zip / .vhdx».
- 🟡 **Сравнение сканов** — «что выросло с прошлого раза» (сохранять снапшот
  в историю).
- 🟡 **Возрастной анализ** — самые старые большие файлы, кандидаты на архив.
- 🟡 **Карта занятости по владельцу** — группа «этот файл принадлежит
  приложению X» (сопоставление с известными корнями очистителей).

## 3. 💽 Диски и здоровье

**Есть:**
- SMART-показатели через Storage cmdlets с откатом на WMI: модель, шина,
  размер, здоровье, температура, наработка, износ, ошибки чтения/записи.
- Проверка поверхности в режиме только чтения (аналог Victoria read test):
  блоки 4 МБ, прогресс, скорость (мг/макс/средняя), список ошибок, отмена.
- Требования прав администратора честно показываются (🔒/✓), кнопка
  перезапуска с UAC.

**Можно добавить:**
- 🟢 **Мониторинг температуры** — опрос раз в N секунд на вкладке, шкала
  с зелёной/жёлтой/красной зоной.
- 🟡 **RAW-атрибуты SMART по ID** — Reallocated Sectors, Pending Sectors,
  Power-On Hours в оригинальных значениях (сейчас только сводные счётчики).
- 🟡 **Связь том ↔ физический диск** — какая буква на каком устройстве
  (Get-Disk/Get-Partition), клик по диску → его тома.
- 🟡 **TRIM для SSD** — `Optimize-Volume -ReTrim` как безопасное действие.
- 🟡 **Вызовы штатных инструментов** — кнопки «chkdsk (только проверка)»,
  «defrag /L» (retrim) с пояснениями.
- 🔴 **График скорости по блокам** — карта поверхности как в Victoria
  (зелёный/жёлтый/красный сектор), лог ошибок с LBA.

## 4. 🔍 Дубликаты

**Есть:**
- Быстрый поиск (имя + размер) и точный трёхфазный (размер → 64 КБ
  префикс → полный BLAKE2b), прогресс и отмена.
- Групповой вид: группы из N копий (сортировка по зря занятому месту),
  первый файл группы — оригинал; удаление всех копий кроме оригинала
  одним пакетным вызовом оболочки, по умолчанию в корзину.
- Минимальный размер файла и лимит результатов.

**Можно добавить:**
- 🟢 **Правила авто-выбора** — «оставлять самый старый / в папке X»,
  «отмечать копии в Temp и Downloads».
- 🟡 **Сравнение между папками** — «найти в A то, что уже есть в B»
  (например, фото на двух дисках).
- 🟡 **Жёсткие ссылки** — показывать, что файл — хардлинк (удаление не
  освободит место).
- 🔴 **Контентный поиск без имени** — группы любых одинаковых файлов
  (уже почти есть в точном режиме) + превью картинок рядом.

## 5. 🚀 Автозагрузка

**Есть:**
- Записи HKCU Run, HKLM Run, HKLM WOW6432Node + папка Startup.
- Обратимое отключение: значение реестра копируется в `startup_backup.json`
  (с типом и исходным значением), файл переименовывается в `*.disabled`.
- Восстановление, добавление своих записей, поиск по списку.

**Можно добавить:**
- 🟢 **Службы** — вкладка «Службы» с типом запуска и переключением
  Авто/Вручную/Откл (тоже обратимо, через бэкап).
- 🟢 **Задачи планировщика** — Task Scheduler \Microsoft\... и пользовательские,
  отключение через `schtasks /Change /DISABLE`.
- 🟡 **Влияние на загрузку** — измерение времени старта записи (Event Log
  Diagnostics-Performance) или хотя бы тег «Высокое/Среднее» из Task Manager
  данных.
- 🟡 **Задержка запуска** — обёртка с sleep для выбранных записей.

## 6. 🗑️ Удаление программ

**Есть:**
- Список из трёх ключей реестра Uninstall (HKLM, HKLM 32-бит, HKCU),
  поиск, версия, издатель, дата установки; сортировка по имени,
  размеру и дате установки.
- Запуск штатного деинсталлятора, поиск остатков на трёх уровнях
  (Safe: AppData; Moderate: + Program Files; Advanced: + реестр).
- Предпросмотр остатков с чекбоксами (по умолчанию ничего не выбрано),
  пакетное удаление файлов и пустых разделов реестра.

**Можно добавить:**
- 🟢 **Пакетный запуск** — очередь деинсталляторов (один за другим).
- 🟡 **Реальный размер на диске** — подсчёт установочной папки, если
  InstallLocation известен (EstimatedSize часто врёт).
- 🟡 **UWP/Store и WinGet** — список пакетных приложений
  (`Get-AppxPackage`, `winget list`) и удаление.
- 🟡 **Тихое удаление** — приоритет QuietUninstallString для пакетного режима.

## 7. 📋 История и отчёты

**Есть:**
- SQLite (WAL) с деталями каждой операции в JSON.
- Вкладка «История»: фильтры по дате, тексту и типу операции
  (Smart Clean / глубокая / очистка), детали записи, экспорт
  отфильтрованного в JSON/CSV (CSV с BOM для Excel).
- Отчёты об очистке на рабочий стол, суммарная статистика освобождённого.
- Отчёт не содержит путей — можно пересылать.

**Можно добавить:**
- 🟢 **График** — освобождено по неделям, простая столбчатая диаграмма
  на Canvas.
- 🟡 **История сканов анализатора** — тренд занятости диска (снапшот при
  каждом скане → график «место кончается к дате X»).
- 🟡 **Прогноз заполнения** — по тренду: «при текущей скорости C: заполнится
  через N недель».

## 8. ⚙️ Настройки и данные

**Есть:**
- Тема (тёмная/светлая/системная), безопасный режим, корзина.
- Экспорт/импорт настроек и правил одним JSON (валидация, опасные пути
  пропускаются с отчётом), атомарная запись конфига.
- Очистка истории, открытие папки данных и лога.

**Можно добавить:**
- 🟢 **Белый список** — «никогда не удалять файлы по маске *.psd / папку X»,
  проверка в планировщике.
- 🟢 **Язык интерфейса RU/EN** — вынос строк в ресурсы (сейчас всё
  захардкожено).
- 🟡 **Автозапуск приложения свернутым в трей** + иконка в системном трее
  с быстрыми действиями.
- 🟡 **Проверка обновлений** — GitHub Releases: сравнение версии, кнопка
  «скачать» (снять SmartScreen-заботу напоминанием про SHA-256).

## 9. 🛡️ Безопасность

**Есть:**
- Уровни 🟢/🟡/🔴 у всех целей, безопасный режим, слои глубокой очистки.
- Защита системных путей, домашних и личных папок; нормализация регистра,
  хвостовых точек/пробелов; junction/symlink никогда не разворачиваются.
- План до удаления с подтверждением, верификация результата по факту.
- Корзина для пользовательских данных (слой D), обратимая автозагрузка,
  остатки программ — только после предпросмотра.

**Можно добавить:**
- 🟡 **Точка восстановления Windows** — `Checkpoint-Computer` перед
  глубокой очисткой/работой с реестром (главная «страховка» уровня ОС).
- Экспорт плана очистки в JSON/CSV прямо из окна предпросмотра плана.
- ~~🟢 Экспорт плана в файл до выполнения~~ — реализовано (см. выше).
  список того, что будет удалено (сейчас план только на экране).
- 🟡 **8.3-короткие имена** в защите путей (`C:\PROGRA~1`) — разворот
  через GetShortPathNameW для существующих путей.

## 10. 🖥️ Интерфейс и платформа

**Есть:**
- CustomTkinter в стиле Material 3: сайдбар, дашборд, статусбар с прогрессом,
  MD3-компоненты, тёмная/светлая тема.
- Дашборд: здоровье диска, выбор диска, топ-5 целей, карточка последней
  очистки. Горячие клавиши Ctrl+S / Ctrl+C / Ctrl+A.
- Безопасная доставка событий из потоков (UiDispatcher), логи с ротацией
  и faulthandler, сборка exe (PyInstaller) + NSIS-установщик + portable,
  CI (Windows) с тестами, ruff, mypy и сборкой.

**Можно добавить:**
- 🟢 **Ленивая сборка вкладок** — сейчас все 10 экранов строятся при старте.
- 🟢 **Git-репозиторий** — инициализировать и закоммитить базовую точку
  (сейчас история изменений не хранится вовсе).
- 🟡 **CLI-режим** — `DiskCleaner.exe --scan --clean safe --report out.json`
  для скриптов/планировщика.
- 🟡 **Компактный режим / масштаб** — слайдер размера шрифта для нетбуков.
- 🔴 **Портирование UI** — если упрёмся в ограничения Tk (нет GPU, слабый
  скролл): Qt (PySide6) или веб-панель (FastAPI + браузер).

## Приоритетная короткая тропа (если делать по чуть-чуть)

1. Git init + коммит текущего состояния (🟢, 5 минут, снимок перед всеми
   дальнейшими изменениями).
2. Docker-очиститель + цели Epic/Java/Adobe (🟢 — по образцу существующих
   файлов в `cleaners/`).
3. Фильтр по типу операции в истории и график освобождённого (🟢).
4. Точка восстановления перед глубокой очисткой (🟡, большой плюс к
   «безопасно»).
5. Службы и задачи планировщика в автозагрузке (🟢/🟡).
6. Групповой вид дубликатов с правилами авто-выбора (🟢/🟡).
