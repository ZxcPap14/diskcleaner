## 1. Очистка мусора и кэшей — против CCleaner, Wise Care 365, BleachBit

**Есть и совпадает с лидерами:** temp Windows/пользователя (с возрастным
фильтром 24 ч), корзина всех томов, кэш эскизов и иконок, WER-отчёты,
дампы приложений и памяти, кэш Windows Update (с управлением службами),
Delivery Optimization, DNS-кэш, GPU-шейдеры (D3SC/NVIDIA/AMD/Intel),
INetCache/WebView2, CBS/DISM-логи, кэши шести Chromium-браузеров и Firefox,
~20 приложений (Discord, Telegram, Steam, Slack, Zoom…), dev-кэши
(npm/pip/yarn/uv/bun/cargo/NuGet/Maven/Conda/VS Code), Docker prune,
AI-модели (Ollama, HuggingFace, Whisper, LM Studio), WSL vhdx.

**Уникальное против аналогов:** auto-discover (поиск безымянных кэшей
по признакам), белый список путей, честный замер «освобождено» по дельте
тома, слой D всегда в корзину, необратимое — только после подтверждения.

**Отстаём от лидеров (найдено при аудите, кандидаты в ROADMAP):**
- UWP/Store-кэши (`Packages\*\AC\INetCache`, LocalCache) — есть у
  CCleaner/Wise; у нас нет.
- Spotify (один из крупнейших кэшей), новые Teams (MSTeams package),
  Go build cache, pnpm store, `cargo\registry\src`, Torch hub,
  NVIDIA ComputeCache — категорий нет.
- Приватность (cookies/история/автозаполнение) — 🚫 принципиально:
  это не «мусор», а данные пользователя.
- Затирание свободного места и шредер — 🚫 (BleachBit/CCleaner имеют).

**Оценка: ~85–90 % объёма очистки CCleaner/Wise на типичной машине
при заметно более строгой модели безопасности.**

## 2. Удаление программ — против Revo Uninstaller, BCU, CCleaner

**Совпадает:** список из HKLM/HKCU (3 ключа), версия/издатель/дата,
реальный размер папки (не только EstimatedSize реестра), очередь
деинсталляторов с остановкой, поиск остатков по уровням (AppData →
Program Files → реестр) с предпросмотром и подтверждением — механика
Revo «uninstall + leftover scan» воспроизведена в безопасной форме.

**Добавлено в 4.11.0 и редкое у конкурентов:** программы со всех дисков
(фильтр «Все диски / C: / D: …»), портативные программы (📦) с удалением
папки строго в корзину, диаграмма «Занято программами» (топ-10 + хвост),
дедупликация «имя + путь» (одно имя на двух дисках не теряется).

**Отстаём:** принудительный сценарий «форс-удаление при сломанном
деинсталляторе», мониторинг установок в реальном времени (Revo),
групповые политики/тихие MSI-массивы (BCU). UWP-пакеты и точка
восстановления перед удалением добавлены в 4.16.0; WinGet-каталог
(`winget list`) пока не показывается.

**Оценка: уровень CCleaner Uninstaller, по остаткам — Revo-lite;
портативные и диаграмма — плюс к классу.**

## 3. SMART и поверхность — против CrystalDiskInfo и Victoria

**Есть:** ATA-атрибуты 5/9/194/197/198 (reallocated, power-on hours,
температура, pending, uncorrectable) через WMI, температурные зоны
«норма/повышена/высокая/критическая», автообновление раз в минуту,
честная подсказка «без прав администратора видно не всё».

**Проверка поверхности** (`services/surface_scan.py`) — чтение сырого
`\\.\PhysicalDriveN` блоками 4 МБ без буферизации: скорость чтения,
подсчёт ошибок (до 200), лимит области, только чтение, admin.

**Против CrystalDiskInfo:** у него полная таблица всех атрибутов
с RAW-значениями и порогами, статус здоровья в %, журнал температуры,
данные прошивки/интерфейса, резидентный мониторинг с оповещениями.
У нас (4.14.0): полная таблица атрибутов с value/worst/порог/raw,
стандартные имена, сводный статус «хорошее/внимание/плохое» по
критическим атрибутам и температуре, показатели для NVMe из
reliability-счётчиков. Чего нет: журнал температуры, данные прошивки,
резидентный мониторинг.

**Против Victoria:** у неё тесты Read/Verify/**Erase (запись)**, карта
блоков, бенчмарк с графиком времени доступа, управление AAM/APM.
У нас — только read-тест с ошибками и скоростью; запись на поверхность
🚫 сознательно (инструмент-очиститель не должен уметь портить диск).

**Оценка: «здоровье» — ~70 % CrystalDiskInfo (полная таблица и статус
есть; нет журнала и резидентного мониторинга); поверхность —
read-only подмножество Victoria.**

## 4. Анализ занятого места — против WizTree, TreeSize, WinDirStat

**Есть:** топ-5000 файлов ≥ 10 МБ за один обход, суммы по расширениям,
фильтры (расширение/размер/возраст), treemap-карта, слой E «крупные
файлы» (топ-50, только просмотр), отмена скана, пропуск junction.

**Отстаём:** WizTree читает MFT и сканирует терабайты за секунды;
WinDirStat/TreeSize показывают полное дерево каталогов любого уровня.
У нас — только крупные файлы и treemap, без дерева «папка → вложенные».

**Оценка: ~50–60 % типового анализатора; для цели «что заняло место»
покрывает главный сценарий, но не исследовательский.**

## 5. Дубликаты — против dupeGuru, AllDup

**Есть:** группы файлов, авто-выбор оригинала (старый/новый/короткий
путь), приоритет корзины для копий в Temp/Downloads, белый список
с меткой 🔒, всё только в корзину с предпросмотром.

**Отстаём:** нет скана по содержимому (хэшам) любых типов, нет выбора
критериев (имя+размер vs содержимое), нет музыкального/картиночного
режимов dupeGuru.

## 6. Автозагрузка — против Sysinternals Autoruns

**Есть:** Run/RunOnce ключи, папки автозапуска, службы, задачи
планировщика, отключение с резервной копией (обратимо), **уникальное**:
влияние на загрузку из журнала Diagnostics-Performance (события 101/103)
с тегом «низкое/среднее/высокое» — Autoruns этого не показывает.

**Отстаём:** Autoruns покрывает ~20+ мест автостарта (драйверы,
shell-extensions, Winlogon, LSA-провайдеры…) и интегрирован с VirusTotal.

## 7. Где мы соответствуем или впереди

- **Модель безопасности**: белый список, «по умолчанию ничего не выбрано»,
  необратимое только после подтверждения, honest-замер освобождённого
  места — у CCleaner/Wise этого набора нет в таком виде.
- **Расписание + тихий режим** (CLI `--smart-clean --silent`) и
  self-test установщика — уровень «взрослых» дистрибутивов.
- **Портативные программы и диаграмма размеров** (4.11.0) — редкость
  в классе деинсталляторов.
- Бесплатно, локально, без рекламы и телеметрии; сборка 14.8 МБ.
