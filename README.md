# 🧹 DiskCleaner Pro

Windows-утилита для очистки диска в стиле CCleaner / BleachBit / WinDirStat.
Написана на Python + CustomTkinter.

## Возможности

- 🧹 **Smart Clean** — системный мусор, кэши браузеров, dev tools, приложений и AI/ML.
  Режимы Easy (только безопасные цели) и Advanced, поиск, сортировка по размеру,
  строки-категории с групповыми чекбоксами (☑/☐/▣) и аккордеоном (свернуть/развернуть),
  кнопка «Безопасные», прогресс по каждой цели и отмена сканирования.
- 🧹 **Глубокая очистка** — 59 целей по слоям A–E: безопасные кэши, системные
  компоненты (DISM, гибернация, старые точки восстановления), компоненты
  и модели, остатки (включая orphan-AppData старше 90 дней — только в корзину).
  Слой E только показывает: крупные файлы (топ-50, открыть папку) и остатки
  обновлений Windows. План до удаления, безопасный набор, предупреждения
  о запущенных приложениях, причины ошибок, кнопки «Повторить» и «Корзина».
- ⏱ **Автоматизация** — баннер на главной при нехватке места (порог
  настраивается), тихая очистка по расписанию в режимах smart / deep-safe
  с точкой восстановления перед запуском.
- 📊 **Анализ диска** — топ папок, файлы с фильтрами по расширению/размеру/возрасту,
  топ расширений, пустые папки, интерактивный treemap
  по выбранному диску; отмена сканирования, кэш результатов с кнопкой «🔄 Обновить»,
  удаление пустых папок и контекстное меню (открыть, скопировать путь, в корзину).
- 💽 **Диски** — SMART-показатели (модель, шина, температура, наработка, износ,
  ошибки чтения/записи), сырые ATA-атрибуты (reallocated/pending sectors,
  power-on hours) с расшифровкой и температурными зонами
  «норма/повышена/высокая/критическая», автообновление раз в минуту на вкладке,
  детали по каждому `PhysicalDrive` и проверка поверхности
  в режиме только чтения (аналог Victoria read test) с прогрессом, скоростью
  и списком ошибок. Сырые атрибуты и проверка поверхности требуют прав
  администратора.
- 🏠 **Главная** — здоровье диска, выбор диска (C:/D:/…), топ-5 крупных целей
  и карточка последней очистки.
- 🔍 **Дубликаты** — быстрый поиск и точное сравнение (размер → 64 КБ → BLAKE2b)
  с прогрессом и отменой; авто-выбор оригинала (самый старый/новый, короткий
  путь), копии из Temp/Downloads удаляются первыми, белый список путей
  неприкосновенен; удаление лишних копий в корзину.
- 🚀 **Автозагрузка** — записи HKCU/HKLM и папка Startup, службы и задания
  планировщика; отключение обратимо (резервная копия в `startup_backup.json`,
  файлы `*.disabled`); влияние на загрузку — медиана запуска из журнала
  Diagnostics-Performance с тегом «низкое/среднее/высокое» (нужны права
  администратора).
- 🗑️ **Удаление программ** — штатный деинсталлятор (QuietUninstallString,
  если есть), реальный размер установочной папки, очередь из нескольких
  программ с остановкой после текущей и отдельный поиск остатков
  с предпросмотром и подтверждением.
- 🧩 **Свои правила** — добавление, изменение и удаление папок/файлов для очистки.
- 📋 **История и отчёты** — отдельная вкладка «История»: фильтры по датам,
  тексту и типу операции, график «Освобождено по месяцам», детали каждой
  записи, экспорт отфильтрованных записей в JSON/CSV.
  SQLite (WAL) и JSON-детали каждой операции.
- 💾 **Резервные копии** — экспорт/импорт настроек и правил одним JSON-файлом
  (атомарная запись, проверка опасных путей при импорте).
- 📝 **Логи** — `%APPDATA%\DiskCleaner\logs\app.log` с ротацией и faulthandler.
- 🌓 Тёмная/светлая/системная тема.

## Требования

- Windows 10/11 (64-бит; на ARM64 работает через эмуляцию x64)
- Python 3.12+ (для запуска из исходников)

## Установка (из исходников)

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -e .
python -m disk_cleaner_app
```

Или без установки пакета:

```powershell
pip install -r requirements.txt
python -m disk_cleaner_app
```

## Разработка

```powershell
pip install -e ".[dev]"
pytest
ruff check .
mypy disk_cleaner_app/models disk_cleaner_app/services disk_cleaner_app/cleaners disk_cleaner_app/ui --ignore-missing-imports
```

## Сборка exe

```powershell
python build.py
```

Результат: `dist\DiskCleaner.exe`.

Для сборки с манифестом `requireAdministrator` (UAC при каждом запуске):

```powershell
python build.py --uac-admin
```

## Сборка установщика

Для установщика нужен [NSIS 3.x](https://nsis.sourceforge.io/Download).
Если `makensis.exe` не в `PATH`, укажите путь явно:

```powershell
python build_installer.py --makensis "C:\Program Files (x86)\NSIS\makensis.exe"
```

Скрипт соберёт exe, установщик и портативный архив:

- `dist\DiskCleaner.exe` — портативная версия (один файл, запускается без установки);
- `dist\DiskCleaner-Setup-4.10.4.exe` — установщик;
- `dist\DiskCleaner-4.10.4-portable.zip` — exe + README + лицензия;
- `dist\SHA256SUMS.txt` — контрольные суммы.

Сборка весит около 15 МБ. NumPy/SciPy/pandas/matplotlib и AVIF/WebP-плагины
Pillow в неё не попадают: приложение их не импортирует, а в граф зависимостей
они приходят через необязательный `squarify.plot`. Список исключений —
`EXCLUDES` в `build.py` и `DiskCleaner.spec`; тест `tests\test_build.py`
следит, чтобы два списка не разъехались.

Установщик ставит приложение в профиль пользователя
(`%LOCALAPPDATA%\Programs\DiskCleaner Pro`), поэтому не требует прав
администратора. Создаются ярлыки в меню «Пуск» и на рабочем столе,
запись в «Программы и компоненты» и деинсталлятор.

Тихая установка и удаление:

```powershell
.\DiskCleaner-Setup-4.10.4.exe /S /D=C:\Tools\DiskCleaner
& "$env:LOCALAPPDATA\Programs\DiskCleaner Pro\Uninstall.exe" /S
```

Для установщика с тем же манифестом:

```powershell
python build_installer.py --uac-admin
```

## Проверка сборки

Собранный exe умеет проверять сам себя без запуска интерфейса:

```powershell
.\dist\DiskCleaner.exe --self-test
```

Проверяются Tk, импорт CustomTkinter/squarify, SQLite, запись в
`%APPDATA%\DiskCleaner` и `%TEMP%`, наличие PowerShell и права
администратора. Отчёт пишется в `%TEMP%\DiskCleaner-selftest.json`
(UTF-8), код возврата 0 — критические проверки прошли. Тот же отчёт
показывает `frozen: true`, то есть запущен именно собранный exe.

Полная проверка установщика на чистой машине (тихая установка → self-test →
удаление) — в PowerShell:

```powershell
.\scripts\verify_installer.ps1 -Setup .\dist\DiskCleaner-Setup-4.10.4.exe
```

Скрипт ставит приложение во временную папку, требует `frozen: true` и
возвращает «4/4 VERIFY OK»; после проверки всё удаляется. Параметр
`-KeepInstall` оставляет установку для ручного осмотра.

Если есть сертификат подписи, exe и установщик можно подписать при сборке
(нужен `signtool.exe` из Windows SDK):

```powershell
python build_installer.py --sign-cert <отпечаток-сертификата>
```

Без сертификата сборка честно предупреждает, что SmartScreen может показать
предупреждение. Проверка совместимости: установщик требует Windows 10/11
x64 (на ARM64 — эмуляция x64) и отказывается работать на 32-битной системе
или Windows 7/8 с понятным сообщением; в тихом режиме возвращает код 2
(версия ОС) или 3 (разрядность).

## Безопасность

- Все операции очистки проходят через уровни 🟢/🟡/🔴.
- Пользовательские пути проверяются: нельзя добавить корень диска,
  `C:\Windows`, `Program Files`, домашний каталог и личные папки.
- Настройка «Перемещать в корзину» применяется к файловым операциям.
  Помните: корзина не освобождает место до её очистки.
- Для операций в системных каталогах могут требоваться права администратора.
  Кнопка 🛡️ в заголовке перезапускает приложение с повышением прав (UAC).
- Автозагрузка отключается обратимо: запись реестра сохраняется в резервную
  копию, файл папки Startup переименовывается в `*.disabled`.
- Остатки удалённых программ удаляются только после предпросмотра в окне
  с чекбоксами: по умолчанию не выбран ни один объект.
- Файлы удаляются пакетно через `IFileOperation` (COM); при недоступности COM
  происходит автоматический откат на `SHFileOperationW`. Корзина — с
  `FOF_ALLOWUNDO`, остатки — с подтверждением в приложении.
- Проверка поверхности только читает `\\.\PhysicalDriveN` блоками и ничего
  не записывает на диск; при отсутствии прав приложение не запускает проверку.
- Импорт настроек не доверяет файлу: неизвестные ключи и опасные пути
  пропускаются и перечисляются в отчёте об импорте.

## Известные ограничения (v4.10.4)

- UAC запрашивается кнопкой 🛡️ либо манифестом при сборке с `--uac-admin`;
  в обычной сборке приложение стартует без повышения прав.
- exe и установщик не подписаны сертификатом: на другом ПК Windows SmartScreen
  может показать предупреждение. Сверяйте SHA-256 с `dist\SHA256SUMS.txt`.
- Установщик поддерживает только Windows 10/11 x64: на 32-битной Windows
  и Windows 7/8 он останавливается с объяснением (в тихом режиме — код 2
  или 3). PyInstaller-сборка может дополнительно вызывать ложные
  срабатывания антивирусов — подпись снижает, но не убирает этот риск.
- Пакетное удаление по умолчанию использует `IFileOperation`, при сбое COM
  автоматически откатывается на `SHFileOperationW`; занятые файлы и очень
  длинные пути могут давать частичные отказы — они перечисляются в логе.
- История ведёт журнал WAL, но не хранит резервные копии удалённых файлов:
  откат возможен только через корзину, и только для файловых операций.
- Полный обход `C:\` в анализаторе может занимать длительное время; сканирование
  мусора, анализ диска и точный поиск дубликатов можно прервать кнопкой «⏹ Стоп».
  Результаты анализа кэшируются до нажатия «🔄 Обновить» или удаления файлов.
- Отчёт «Файлы и фильтры» обходит диск один раз: фильтры по расширению, размеру
  и возрасту пересчитываются по уже собранным данным, без повторного скана.
- Выбор диска на главной применяется к анализатору: топ папок, файлы с
  фильтрами, пустые папки и treemap работают с выбранным диском. Очистка
  по-прежнему удаляет только пути, принадлежащие целям очистки.
- SMART зависит от драйвера и прошивки: на части NVMe и USB-дисков температура,
  наработка и износ недоступны — в таблице показывается «—».
- Влияние автозагрузки читается из журнала Diagnostics-Performance: нужны права
  администратора и события за последние 30 дней. Без них в колонке «Влияние»
  стоит «—», а подсказка объясняет причину.
- Проверка поверхности читает сырое устройство и требует прав администратора;
  полная проверка HDD может длиться часы, её можно прервать кнопкой «⏹ Стоп».
- Фильтр истории ищет по дате, целям, статусу и заметкам; фильтра по типу
  операции пока нет.
- Экспорт отчёта не содержит путей к файлам — только цели, объём и дату.
- `DISM /StartComponentCleanup` может работать до 15 минут; `/ResetBase`
  сознательно не используется, поэтому старые версии компонентов остаются
  доступными для отката.
- Отключение гибернации освобождает `hiberfil.sys`, но до команды
  `powercfg /hibernate on` не работает быстрый запуск.
- Очистка VSS удаляет старые точки восстановления безвозвратно, оставляя
  самую новую на каждом томе; для неё нужны права администратора.
- `Windows.old`, `$WINDOWS.~BT`, `$WinREAgent` и ESD только показываются
  с подсказкой — приложение их не удаляет, это делают штатные средства Windows.
- Тихая очистка по расписанию в режиме deep-safe запускает только слой A
  и рекомендованные цели; точка восстановления создаётся не чаще раза в 24 ч.

## Структура

```
disk_cleaner_app/
├── models/      # конфиг, история, модели данных
├── services/    # сканирование, очистка, анализ, дубликаты, отчёты, диагностика дисков
├── cleaners/    # цели очистки по категориям
└── ui/          # CustomTkinter: окна, компоненты, темы

assets/          # иконка приложения и картинки установщика
installer/       # NSIS-сценарий установщика
build.py         # сборка exe (PyInstaller)
build_installer.py # exe + установщик + portable ZIP
```

## Данные приложения

Всё хранится в `%APPDATA%\DiskCleaner`:

- `config.json` — настройки (атомарная запись);
- `custom_rules.json` — пользовательские правила;
- `history.db` — история очисток (SQLite, WAL);
- `startup_backup.json` — резервные копии отключённых записей автозагрузки;
- `logs\app.log` — журнал приложения (ротация 1 МБ × 3);
- `logs\faulthandler.log` — дампы при аварийном завершении.

Открыть папку и лог можно в «Настройках → История очисток».
