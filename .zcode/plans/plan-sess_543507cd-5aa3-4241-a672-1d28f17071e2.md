### 🔧 Технические улучшения

#### Threading
```
ScanEngine:
  ThreadPoolExecutor(max_workers=4)
  → Параллельное сканирование групп cleaner'ов
  → Каждый cleaner — отдельный future
  → Callback на главный поток через root.after()

CleanEngine:
  Последовательное выполнение (безопасность)
  Каждый шаг: confirm → clean → verify
  Прогресс: item-based
```

#### BaseCleaner — абстрактный класс
```python
class BaseCleaner(ABC):
    name: str
    group: str
    safety: SafetyLevel
    description: str
    can_preview: bool

    @abstractmethod
    def get_size(self) -> int: ...
    @abstractmethod
    def clean(self) -> tuple[str, str]: ...
    def preview(self) -> list[dict]: ...
```

Вместо замыканий — полноценные классы. Это позволяет:
- Тестировать каждый cleaner изолированно
- Добавлять новые cleaner'ы без редактирования `define_items()`
- Переиспользовать логику (наследование)
